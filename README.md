# NEON SNIPE // FPS Training Simulation

A polished, dependency-free browser sniper range built with HTML Canvas, CSS, and vanilla JavaScript.

## Features

- Interactive moving-target sniper range with five rounds and elite targets.
- Click-to-fire accuracy gameplay, wind readout, zoom wheel control, ammo, reload, combo, critical hits, and daily contract progress.
- Customizable tune profiles: Precision, Rapid Cycle, Steady Hand, and Overdrive.
- Six camo finishes with Common, Rare, Epic, and Mythic rarity, animated/reactive previews, and different color palettes.
- Responsive layout for desktop and mobile, with an accessible start button and keyboard controls.

## Controls

- **Click** — fire
- **Mouse wheel** — adjust scope zoom
- **R** — reload
- **Esc** — abort mission

Open `index.html` in a browser or deploy the repository with GitHub Pages. No build step is required.
